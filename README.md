# TrafficVision
### AI-Based Real-Time Traffic Violation Detection and Automatic Number Plate Recognition System

## 1. Project Overview

TrafficVision is a proposed AI-based system designed to detect selected traffic violations from video footage and identify vehicle registration numbers using Automatic Number Plate Recognition (ANPR).

The system aims to combine computer vision, object detection and Optical Character Recognition (OCR) to generate timestamped records of suspected traffic violations.

## 2. Project Objectives

- Process traffic video footage frame by frame.
- Detect vehicles, riders and selected traffic violations.
- Detect and extract vehicle number plates.
- Recognise registration numbers using OCR.
- Store violation records in a local database.
- Generate warning notifications for identified test records.

## 3. Proposed Technology Stack

| Component | Technology |
|---|---|
| Programming Language | Python |
| Video Processing | OpenCV |
| Object Detection | YOLO |
| Number Plate Recognition | OCR |
| Database | SQLite |
| Data Storage | CSV / SQLite |

## 4. Proposed System Workflow

1. Video input
2. Frame extraction and preprocessing
3. Vehicle and violation detection
4. Number plate detection and cropping
5. OCR-based number plate recognition
6. Database lookup
7. Violation logging and warning generation
